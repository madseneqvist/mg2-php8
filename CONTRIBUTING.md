# Contributing

Contributions that preserve MG2's small, dependency-free character are welcome.

1. Fork the repository and create a focused branch.
2. Never add real gallery data, images, logs, settings, credentials, or backups.
3. Preserve copyright and license notices in inherited files.
4. Test changes on every supported PHP version and with warnings enabled.
5. Describe behavior changes, security impact, and manual verification in the
   pull request.

Security reports should follow [SECURITY.md](SECURITY.md), not public issues.
